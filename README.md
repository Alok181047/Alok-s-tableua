# 🌍 Global Olympic Sports Performance Analysis

## 📌 Project Overview

The **Global Olympic Sports Performance Analysis** project focuses on analyzing Olympic sports data to understand medal achievements, athlete participation, country-wise performance, regional trends, and sport-category distributions.

The project uses data visualization to explore Olympic performance patterns and present meaningful insights through an interactive Tableau dashboard.

## 🎯 Project Objectives

- Analyze medal achievements across different countries.
- Explore athlete participation trends across Olympic editions.
- Compare country-wise and regional sporting performance.
- Examine medal distribution across different sports.
- Identify patterns in Olympic performance over time.
- Present data-driven insights using interactive visualizations.

## 🛠️ Tools & Technologies

- **Tableau Public** — Interactive dashboards and data visualization.
- **HTML5** — Website structure and content.
- **CSS3** — Website styling and responsive design.
- **GitHub** — Source code hosting and project management.
- **GitHub Pages** — Static website hosting.

## 📊 Key Analysis Areas

## 🚀 How to Run the Project

### View the Website Locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Navigate to the dashboard page to access the Tableau visualization.

### View the Tableau Dashboard

1. Open the published Tableau Public dashboard.
2. Use available filters and charts to explore the data.
3. Replace the placeholder Tableau URL in `tableau.html` with your published dashboard URL if you want to embed it in the website.

## 🌐 Deploy Using GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Click **Save**.
6. Open the published website URL shown in GitHub Pages settings.

Your website URL will follow this format:

`https://YOUR-USERNAME.github.io/Global-Olympics-Analysis/`
